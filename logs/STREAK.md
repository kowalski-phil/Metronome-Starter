# STREAK — the streak tracker

How the streak is counted (agree on this before week 1):
- One public upload per **calendar week (Mon–Sun, [your time zone])**. Zero uploads in a week = **missed week**.
- Two uploads in one week do **not** fill a past miss.
- A week counts only if its row has **URL + upload date + a check of the public page** (title, channel, actually public).
- Don't call the engine "proven" before the final review.
- One missed week = flagged, the next week runs as normal. [Three] in a row = written freeze note.
