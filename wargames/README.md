# wargames/

Your plan for the whole run gets written here as `plan.md`. Claude writes it from `tasks/01-mission-brief.md` (see the README, step 4).

**What the plan is:** the whole run fought on paper before you start. Phase by phase, it asks what you expect to see if a step works, what you'll see if it fails, and what you do then. It's graded against `SUCCESS.md`.

**Why bother:** most weekly-video attempts die the same few ways: the scope slowly grows, you get demoralised by silence, or other priorities eat the slot. A plan that names those in advance, with a pre-agreed response to each, is much harder to quietly abandon.

Optional: also ask for an HTML version with diagrams (`plan.html`) if you like a visual map.
